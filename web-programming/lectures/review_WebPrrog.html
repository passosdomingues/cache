HTML

Qual é a função principal do HTML?

O HTML (HyperText Markup Language) é responsável pela estrutura e semântica do conteúdo web. Ele define a hierarquia e o significado dos elementos na página.

CSS

O que significa CSS?

CSS significa Cascading Style Sheets (Folhas de Estilo em Cascata). É a linguagem usada para estilizar elementos HTML, controlando layout, cores, fontes e outros aspectos visuais.

JavaScript

Qual é o papel do JavaScript no desenvolvimento web?

JavaScript adiciona interatividade e comportamento dinâmico às páginas web. Permite manipular o DOM, responder a eventos do usuário e criar experiências ricas.

HTTP

O que é o protocolo HTTP?

HTTP (HyperText Transfer Protocol) é o protocolo de comunicação usado para transferir dados na web. Define como as mensagens são formatadas e transmitidas entre clientes e servidores.

DOM

O que é o DOM?

DOM (Document Object Model) é uma representação em árvore do documento HTML que o navegador cria. Permite que JavaScript acesse e manipule elementos da página.

WordPress

Qual é a principal vantagem do WordPress?

WordPress é um CMS (Content Management System) que permite criar e gerenciar sites sem necessidade de codificação extensiva. Oferece flexibilidade através de temas e plugins.

📚 HTML Semântico

O HTML semântico usa elementos que descrevem claramente seu significado tanto para o navegador quanto para o desenvolvedor.

Vantagens:

  • Melhor acessibilidade
  • Otimização para SEO
  • Manutenção mais fácil do código
  • Melhor compreensão da estrutura

Exemplos de elementos semânticos: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>

🎨 CSS - Box Model

O Box Model é um conceito fundamental no CSS que descreve como os elementos são renderizados na página.

Componentes do Box Model:

  • Content: O conteúdo real do elemento (texto, imagem, etc.)
  • Padding: Espaço entre o conteúdo e a borda
  • Border: A borda ao redor do padding
  • Margin: Espaço externo ao elemento, separando-o de outros elementos

Fórmula: Largura total = width + padding-left + padding-right + border-left + border-right + margin-left + margin-right

⚙️ JavaScript - DOM Manipulation

A manipulação do DOM permite modificar dinamicamente a estrutura, estilo e conteúdo de uma página web.

Métodos comuns:

  • document.getElementById() - Seleciona elemento por ID
  • document.querySelector() - Seleciona o primeiro elemento que corresponde ao seletor
  • element.innerHTML - Altera o HTML interno de um elemento
  • element.style.property - Altera o estilo de um elemento
  • element.addEventListener() - Adiciona um ouvinte de evento
