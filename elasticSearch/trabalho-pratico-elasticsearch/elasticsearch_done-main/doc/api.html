Wikipedia Search API (2.0.0)

Download OpenAPI specification:

License: MIT

API RESTful para busca de documentos Wikipedia via Elasticsearch. Suporta busca full-text com fuzzy matching, highlight de termos, paginação com total de resultados e sugestões de correção ortográfica.

search

Operações de busca full-text no índice Wikipedia

Realiza busca full-text no índice Wikipedia

Executa uma query booleana com must + should (phrase boost) contra os campos content e title do índice Wikipedia. Suporta fuzzy matching automático (fuzziness: auto) e highlight de termos encontrados. Retorna cabeçalhos HTTP com metadados de paginação.

query Parameters
query
required
string non-empty
Example: query=square root

Termo ou frase a ser buscado. Suporta erros de digitação via fuzzy matching.

page
integer >= 1
Default: 1
Example: page=1

Número da página de resultados (1-indexed)

size
integer [ 1 .. 50 ]
Default: 10
Example: size=10

Quantidade de resultados por página

Responses

Servidor local de desenvolvimento

http://localhost:8080/v1/search

suggest

Sugestões de correção ortográfica e autocomplete

Sugestões de correção ortográfica para um termo

Utiliza o mecanismo de Term Suggest do Elasticsearch para corrigir erros de digitação e sugerir termos alternativos baseados no vocabulário do índice Wikipedia. Útil para o recurso "Você quis dizer?" na UI.

query Parameters
query
required
string non-empty
Example: query=Kolmogorv equatons

Texto com possíveis erros ortográficos para o qual se deseja sugestões

size
integer [ 1 .. 10 ]
Default: 3
Example: size=3

Número máximo de sugestões por termo

Responses

Servidor local de desenvolvimento
