## Como Usar Esta Ontologia no Obsidian

Download: https://obsidian.md/download

### **1. Navegação pelo Grafo**
- Use a visualização de grafo para ver as conexões entre conceitos
- Clique em qualquer link `[[desta forma]]` para navegar entre notas
- Crie novas notas automaticamente clicando em links não existentes

### **2. Expansão da Ontologia**
- **Conceitos Prioritários para Desenvolver**:
  - [[Planejar]], [[Organizar]], [[Dirigir]], [[Controlar]] (funções específicas)
  - [[Metas SMART]], [[Ciclo PDCA]], [[Matriz RACI]] (ferramentas)
  - [[Scrum]], [[Kanban]], [[Lean]] (frameworks específicos)

- **Áreas para Aprofundamento**:
  - Crie notas para cada ferramenta mencionada
  - Desenvolva casos de uso específicos por indústria
  - Adicione templates para cada tipo de documento de projeto

### **3. Aplicações Práticas**
- **Para Planejamento**: Comece com [[Processo Fundamental]] e [[Elementos Essenciais]]
- **Para Seleção Metodológica**: Consulte [[Visão Geral de Gestão]] e [[Comparativo: Cascata VS Ágil]]
- **Para Melhoria Contínua**: Siga [[Ciclo de Gestão de Riscos]] e [[Aprendizado Contínuo]]

### **4. Personalização**
- Adicione exemplos de sua organização
- Crie notas de caso conectando conceitos a projetos reais
- Desenvolva checklists baseados nos conceitos
- Adapte as tags para seu contexto específico
