# Queueing System Simulator and Analysis Package

## Overview
This project implements an event-driven queueing system simulator in C and a comprehensive statistical analysis package in Python. The system models a single server serving three independent queues with configurable selection policies.

## Features

### C Simulator
- Three configurable queue selection policies
- Support for multiple occupancy scenarios (ρ = 0.80, 0.90, 0.95, 0.999)
- Comprehensive metrics sampling every 10 seconds
- Little's Law validation with proof files
- Batch processing with reproducible seeds

### Python Analysis Package
- Automated stabilization detection
- Bootstrap error propagation
- Machine learning workflows (PCA, k-means, Random Forest)
- Comprehensive visualization and reporting
- Statistical validation and diagnostics
