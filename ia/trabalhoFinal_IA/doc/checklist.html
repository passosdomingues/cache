Este checklist guiará você através das oito etapas principais de um projeto de Machine Learning:

  1. Enquadre o problema e veja o panorama geral
  2. Obtenha os dados
  3. Explore os dados para obter insights
  4. Prepare os dados para os algoritmos
  5. Explore modelos e selecione os melhores
  6. Ajuste seus modelos e combine soluções
  7. Apresente sua solução
  8. Lance, monitore e mantenha seu sistema
